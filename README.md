# DivineJustice Anthony Samuel · Portfolio

Personal portfolio of a Software Engineer & Cloud Solutions Architect, covering web, mobile, and cloud work.

Built with React 19, TypeScript, Vite, Tailwind CSS v4, and Motion.

## Run locally

Requires Node.js 20+.

```bash
npm install
npm run dev      # http://localhost:3000
```

## Scripts

| Command           | What it does                    |
| ----------------- | ------------------------------- |
| `npm run dev`     | Start the dev server            |
| `npm run build`   | Production build into `dist/`   |
| `npm run preview` | Serve the production build      |
| `npm run lint`    | Type-check with `tsc`           |

## Editing content

- Profile, projects, experience, leadership, skills: [`src/data/portfolioData.ts`](src/data/portfolioData.ts)
- Tools grid: [`src/data/tools.ts`](src/data/tools.ts) (logos in `src/assets/tools/`)
- Project and community logos: `src/assets/images/`
